# 测试

## 自动化自测(纯逻辑)

`./gradlew selfTest` 以 JavaExec + JUnitCore 运行全部断言
(`test/bsp/`,65 个用例;新套件须登记进 `SelfTestRunner`)。
`./gradlew build` 强制先跑自测,任何失败即构建失败。

覆盖面:

| 套件 | 重点 |
| --- | --- |
| ThreatModelTest | 多目标上限、弹种形状、护甲下限、盲区、命中率衰减、状态伤害、地/空覆盖、Auto 推断 |
| ThreatGridTest | 射程内/外、盲区、多源叠加、悬停明细与格值一致、自动避让掩码(范围/外扩余量/盲区敞开/不可交战源不掩蔽) |
| CostModelTest | 滑杆映射端点与单调性、谨慎权重、shortestOnly、液体减速、地块伤害进统计 |
| AStarTest | 直线、绕墙、禁穿角、无解、阻塞端点、绕开高代价带 |
| LiquidPolicyTest | 生存公式(镜像游戏公式)、预留时间让边缘穿越不安全 |
| PathPlannerTest | **液体边界回归组**:跨矿渣+深水仍出路线(v5.2.2 类死角)、可生存穿越优先于强制、可绕行时严格轮避水、关闭可生存穿越时走强制轮、液体围死目标的替代终点、空军无视溺水液体、实心墙无解返回 null、三色风险阈值 |
| WaypointCompactorTest | 直线 2 点、L 型 3 点、上限强制保首尾、缓曲线抽稀 |
| ClusterSplitterTest | 两群分割、链式合并、单点/空集 |
| PowerClusterFinderTest | 聚类与最小规模、topN 排序、炮塔侧接近点、从玩家出发 |
| ChatCoordinateParserTest | 中英标点、首个坐标优先、非法拒绝、越界钳制 |
| GridUtilsTest | 世界↔格换算、钳制、螺旋搜索 |

液体/深水场景是历史上反复出问题的边界,`PathPlannerTest` 的前六个用例
即回归门槛,不得删改语义(可随实现重构调整内部,断言行为不变)。

## 结构化手测清单(运行时行为,可勾选)

环境:桌面 Mindustry v7 build ≥154;建议两种环境各跑一遍:
原版客户端、装了 MindustryX 的客户端。

前置:
- [ ] 安装 betterStealthPath-dev.jar 后模组列表不显示(hidden 生效),无报错刷屏
- [ ] 无 MindustryX 环境加载不崩溃,HUD 三窗口出现(左上角)
- [ ] 有 MindustryX 环境时三个窗口成为 OverlayUI 可拖拽窗口,可拖动/缩放/记忆位置

手动预览(X/Y):
- [ ] 点按 X 计算一次;按住 X 每 0.10s 重算,鼠标移动路线跟随
- [ ] 松开后路线保留 10s(默认)消失;设 0 时保留到下次计算
- [ ] 路径中段显示"~-N"预计受伤;Y 模式(含敌方单位)数值高于 X
- [ ] 不在游戏/无单位/无目标/无路径时对应 toast,不绘制
- [ ] 聊天框输入焦点时按 X/Y 无响应;绑定修饰键后需组合键触发

目标模式(K 循环五档):
- [ ] 最近敌方核心:K=1 一条;核心数设 3 时画三条并 toast 最小受伤
- [ ] 最近敌方建筑 / 指定建筑(选择器可选、仅该模式生效)
- [ ] 发电集群:每个有价值群画一条"接近点→群心"渗透路线(默认 3 条);
      默认从炮塔侧接近,勾选后从玩家出发
- [ ] 鼠标位置:终点跟随鼠标;设置切换"目标点"后出现圆圈+十字手柄,可拖动
- [ ] 设置页"目标模式"五档/"威胁过滤"四档按钮与 K/L 循环结果一致,即时生效

威胁过滤(L 循环 AUTO/陆/空/混合):
- [ ] 默认 AUTO:框选陆军 → 只看对地火力;混入空军 → 混合口径,无需手动切换
- [ ] 手动选错档位时路线明显误判(语义验证开关真实生效)

自动模式(N 集群→鼠标,M 集群→聊天坐标):
- [ ] N 开后持续规划,toast 反馈;静止且无变化时重算频率明显下降(路线不抖)
- [ ] 聊天发送 "(100,150)" 后 M 模式以该点为目标;超界坐标被钳制
- [ ] 未有坐标时按 M 提示"请在聊天发送 (x,y)"
- [ ] 编队拆成多集群(相距 >5 格)时各自画线、各自移动
- [ ] 三色:预估受伤 <10 绿;更高但人均不至于死黄;预计死人为红(颜色可自定义)

自动移动:
- [ ] 自动模式下单位沿路点行进,接近 2 格切下一路点;到点推进不卡岸边
- [ ] 下一路点进入深水等可溺水液体前收紧为严格到点(不抄角下水)
- [ ] 目标处于炮塔群覆盖内时自动模式仍出路线(避让带自动放宽,threatExpand)
- [ ] 分帧设 8/30 时多集群自动规划分摊到多帧,无单帧长卡顿
- [ ] 路线无实质变化时不重发(6 小时观察不到指令风暴;F8 日志可见节流)
- [ ] 大编队(≥16)分批下发、大单位先行
- [ ] 完全无安全路线时退化为直奔目标
- [ ] 单位死亡/世界切换后路径与自动状态清空重算

液体与深水:
- [ ] 含深水地图上,可溺水地面单位不会被规划进危险深水段(绕行)
- [ ] 跨矿渣+深水场景仍能出路线(强制轮时伤害标签带 "!")
- [ ] 目标被深水围死时找到岸边替代终点而非直接失败
- [ ] 关闭"允许可生存液体穿越"后不再出现窄段穿越

调试与 UI:
- [ ] J 切换热力图,数值叠层与直觉一致(炮塔覆盖圈红、盲区空)
- [ ] 开启悬停 DPS 后伤害窗口列出鼠标格位的炮塔明细(约 0.25s 节流)
- [ ] 三个窗口开关同时控制 HUD 与 OverlayUI 两态;玩家在 OverlayUI 的
      显示/钉住选择不被覆盖
- [ ] 设置全部即时生效(改线宽/颜色/阈值立刻反映到下一次绘制)

更新检查:
- [ ] 设置仓库为空时不检查;dev 身份(0.0.0)跳过
- [ ] 配置仓库后有新版本时主菜单弹窗(6 小时内不重复);"打开 GitHub /
      经镜像打开 / 忽略 / 稍后"行为正确;镜像前缀可配
- [ ] 关闭弹窗提示后仅轻量 toast;整体关闭后完全静默

聚合态:

      其余功能不变(对照独立态)

      (威胁图按源集合签名 + 0.5s 粒度缓存)
